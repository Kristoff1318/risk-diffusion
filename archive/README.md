# Archived research

The active project is [Maze2D Chance](../maze2d_chance/README.md).

`prior_studies/` contains the earlier point-agent studies, original pilot,
revision, inspection, phases 1–13, Panda experiments, validation adapter,
outputs, preservation records, and their documentation. Original relative
structure inside this historical project has been retained. No scientific
file content was changed during relocation.

`prior_studies_manifest.json` records original and archived paths, byte counts,
and SHA-256 hashes for all 1,355 relocated files, verified after moving them.
It includes ignored generated outputs, not only Git-tracked files.

Historical reports retain their original dates, conclusions, hyperlinks, and
machine-specific paths. Root/package-qualified commands and absolute paths
may require the original checkout layout; these reports are not active run
instructions. To reproduce an old study, use its recorded revision in a
separate checkout. The old branch `improve/nonlinear-risk-calibration` remains
available. No historical output is deleted or silently updated.

The PowerPoint remains at the project root because it specifies the active
research question. The older RB Diffuser repository and checkpoint remain
external, read-only dependencies.
